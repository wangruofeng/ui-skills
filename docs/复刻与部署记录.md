## 依据与范围

参考站 https://www.ui-skills.com/；源代码 https://github.com/ibelick/ui-skills，MIT。基于 main 的公开代码分叉，保留上游历史、作者和许可证。

## 实施

- 独立静态 Astro 构建，去除需要原作者 OAuth、D1 和商业服务的本地入口，跳转原站对应服务。
- 去除原作者统计和赞助悬浮广告；保留来源署名。
- 共享界面字典用于构建期 HTML 与搜索等交互内容；明确保护技能原文区域与代码。
- 双语导航、每页 canonical/hreflang、由真实构建页面生成 sitemap；保留 404 noindex。
- 本地化 46 个公开图片资源；每次构建保存上游不可用清单，详情明确提示正文不可用。
- GitHub 公开分叉仓库 wangruofeng/ui-skills；Cloudflare Pages Git 集成，main 自动部署。

没有提交搜索引擎站长后台，不宣称已收录或排名提升。

## GitHub 登录与收藏（2026-11-16）

复用上游 Better Auth、账号数据库 schema 与收藏存储。新增同源 Pages Functions，公开页面继续静态部署。新注册的本站 OAuth App 仅使用精确 HTTPS 回调，不启用通配符和设备授权。独立 D1 `ui-skills-auth` 已初始化两份迁移；生产凭据只存 Cloudflare secret_text，预览关闭登录并禁用生产数据库绑定。

新增中文和英文登录、我的收藏页与详情星标；未登录收藏跳转本站登录并保存返回路径；登录后按账号保存、移除和跨会话加载收藏。账号 API 带 private/no-store、noindex，收藏写入校验 Origin 和已登录用户。

新增账号组件使用内部双语渲染，避免静态页面翻译脚本修改 React 初始化期间的内容。
